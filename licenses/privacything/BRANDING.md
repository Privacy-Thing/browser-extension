# Privacy Thing Branding and Attribution Policy

“Privacy Thing” is the name of the original browser extension project created and
maintained by Tomasz Janusz.

This policy applies to the Privacy Thing name, project identity, logo, icon,
screenshots, store listing text, visual identity, and other branding materials
associated with the original Privacy Thing project.

The software license for Privacy Thing grants rights to use, copy, modify, and
distribute the Privacy Thing source code under the terms of that license. It does not
grant permission to misrepresent the origin of the software, imply endorsement,
or publish modified versions in a way that is likely to confuse users.

## Permitted uses

You may use the name “Privacy Thing” only to truthfully describe the origin of the
software, for example:

- “Based on Privacy Thing”
- “Forked from Privacy Thing”
- “Uses code from Privacy Thing”
- “Derived from Privacy Thing by Tomasz Janusz”

You must preserve the following attribution notice in source distributions,
documentation, and any About, Legal, Credits, Acknowledgements, Licenses, or
equivalent notice screen where project notices are shown:

> Based on Privacy Thing by Tomasz Janusz — https://privacything.com

## Modified versions and forks

If you distribute, publish, upload, or make available a modified version or fork
of Privacy Thing, including through a browser extension store, package registry,
marketplace, website, or repository, you must:

1. use a name that clearly distinguishes your version from the original Privacy Thing;
2. clearly state that your version is modified;
3. clearly state that your version is not the official Privacy Thing project;
4. not imply endorsement, sponsorship, maintenance, approval, publication, or
   affiliation by Tomasz Janusz or the original Privacy Thing project;
5. preserve the required attribution notice;
6. not remove, obscure, or replace copyright, license, attribution, or
   third-party notices.

## Store listings and public distribution

A fork or modified version must not be published in a browser extension store,
marketplace, package registry, website, repository, or public catalog in a way
that is likely to confuse users into believing that it is the original or
official Privacy Thing project.

In particular, a fork or modified version must not:

- use “Privacy Thing” as its primary product name in a confusing or misleading way;
- use “Official Privacy Thing”, “Privacy Thing Pro”, “Privacy Thing Plus”, or similar
  names that imply an official relationship;
- copy the original Privacy Thing store listing in a way that misrepresents authorship;
- use the original Privacy Thing logo, icon, screenshots, or visual identity in a way
  that suggests the fork is official;
- list Tomasz Janusz as the publisher, maintainer, sponsor, or author of the
  modified version unless expressly authorized in writing.

## Allowed examples

Allowed:

> Location Masker — based on Privacy Thing

With this notice:

> This is an independent modified version based on Privacy Thing by Tomasz Janusz:
> https://privacything.com. It is not affiliated with, endorsed
> by, or maintained by the original Privacy Thing project.

Allowed:

> Privacy Thing Community Fork

Only if the listing clearly states:

> This is an independent fork of Privacy Thing. It is not the official Privacy Thing project
> and is not affiliated with, endorsed by, or maintained by Tomasz Janusz.

## Not allowed examples

Not allowed:

- “Privacy Thing” as the name of a modified listing that appears official;
- “Official Privacy Thing”;
- “Privacy Thing Pro”;
- “Privacy Thing Plus”;
- “Privacy Thing by [someone else]”;
- any listing that presents a fork as the original Privacy Thing project;
- any listing that copies Privacy Thing branding in a way likely to confuse users.
