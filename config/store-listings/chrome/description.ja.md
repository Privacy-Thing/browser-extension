もっと知る。見せる情報は少なく。

Webサイトがブラウザから読み取れるのは、フォームに入力した内容だけではありません。位置情報、言語、タイムゾーン、画面サイズ、ハードウェア特性など、さまざまな環境情報にアクセスできます。WebGL が公開するグラフィックス情報さえ、ブラウザフィンガープリントの一部になり得ます。

Privacy Thing は、この層のプライバシーを実用的に管理するためのツールです。ブラウザで開いているページがどの情報や機能にアクセスしているかを表示し、そのサイトに見せる情報をサイトごとに選べます。

要点
==================================================

1. Privacy Thing では、ブラウザがWebサイトやWebアプリに渡す情報を管理できます。
2. どのデータが使われ、何回参照されたかを確認できます。
3. サイトごとに複数のルールセットを作成できます。
4. 地理的な位置、利用可能な言語、地域設定を基に、複数の位置設定を作成できます。Privacy Thing には、GPS位置情報を現実的な移動モデルで再現する本格的なシミュレーション機能があります。
5. Privacy Thing は、外部サービスへの接続をできるだけ必要とせず、多くの機能を利用できるよう設計されています。設定の主導権はあなたにあります。

Privacy Thing でできること
==================================================

1. ブラウザの「デジタル指紋」の一部を抑える

ブラウザと設定に応じて、Privacy Thing はブラウザ、画面、ハードウェアに関する一部の情報に加え、canvas、WebGL、Audio API、WebRTC、フレーム、ワーカーの選択された値を制御または変更できます。グラフィックスハードウェアの特徴を示す可能性がある情報も含まれます。

Privacy Thing は、拡張機能が技術的に扱える範囲の情報を制限し、整理するための具体的な手段を提供します。

2. サイトが何を読み取ったか確認する

内蔵診断ツール X-Ray では、サイトが位置情報、言語、画面データ、canvas、WebGL、Audio API、WebRTC、一部のワーカー機構にアクセスしたかを確認できます。適用されたプロファイルや、対応カテゴリで発生した問題も表示されます。

これはサイトの全動作を記録する完全なログではありません。Privacy Thing が認識・制御できるブラウザ領域を実用的に確認するための機能です。

3. サイトごとに自分のルールを設定する

プロファイルを作成し、ドメインまたはドメインパターンに割り当てます。既定ルールや特定サイトの例外を利用でき、設定を削除せずに Privacy Thing を一時停止することもできます。選んだサイトだけで拡張機能を使うこともでき、Privacy Thing が一つの使い方を押し付けることはありません。

4. 一貫した地域プロファイルを作成する

プロファイルには、座標、位置情報の精度と座標の変動範囲、主要言語、言語リスト、タイムゾーンをまとめられます。初回起動ウィザードでは地域プリセットをすぐに選べ、自分で作ったプロファイルは後から自由に編集できます。

Refract エンジンは Geolocation API、navigator.language、navigator.languages、Date、Intl、Accept-Language などをそろえられます。位置はある国、言語は別の国、タイムゾーンはさらに別の地域、といった不自然な組み合わせを減らせます。

5. 不要な通信なしで現実的なデータを利用する

Privacy Thing の各リリースには、公開データを加工した小規模なローカルカタログが含まれます。拡張機能は追加の通信を行わずに、統計的に不自然でない画面解像度、CPUコア数、使用可能メモリを組み合わせたハードウェアプロファイルを自動で選べます。

Privacy Thing は、実在する Chromium リリースのカタログを使い、サイトから見えるブラウザバージョンを切り替えることもできます。ブラウザが対応する言語コードと、公用語のカタログも内蔵しています。

これらのデータは拡張機能に同梱され、更新時に定期的に刷新されます。通常のプロファイル適用時に元の情報源へ問い合わせる必要はありません。座標からタイムゾーンをローカルで判定することもできます。

6. 選んだサイトのデータを消去する

Privacy Thing は、現在のドメインの Cookie、localStorage、sessionStorage、IndexedDB、Cache Storage、Service Worker を削除できます。プライバシー管理にも、クリーンな状態からのサイトテストにも役立ちます。処理が完了すると、プロファイルのパラメータ一式がまったく別のものに更新され、サイトが活動を継続的に追跡しにくくなることが期待できます。

データはあなたのもの。決めるのもあなたです。
==================================================

プロファイル、ルール、設定はブラウザ内に保存されます。基本機能に Privacy Thing アカウントや専用サーバーは不要です。独自のテレメトリデータを収集せず、データを販売することもありません。

プリセット、ローカルカタログ、手入力した座標は、地図サービスへのリクエストなしで利用できます。場所検索や地図プレビューを自分で有効にした場合にだけ、OpenStreetMap Nominatim と OpenFreeMap を使用します。この選択は後から変更できます。

プライバシー対策には複数の層があります
==================================================

Privacy Thing が制御するのは、ブラウザのインターフェースからサイトが直接読み取る一部の情報です。公開 IP アドレスを変更せず、通信を経路変更・暗号化せず、VPN、プロキシ、Smart DNS の代わりにはなりません。

これらは問題の別の層を扱うため、組み合わせて利用できます。VPN、プロキシ、Smart DNS はネットワークや名前解決に作用し、Privacy Thing はブラウザ API を通してサイトに見える情報を扱います。

Privacy Thing は匿名性や、変更が検出されないことを保証しません。サイトは IP アドレス、アカウント情報、セッションなど、拡張機能が制御できない信号も利用できます。X-Ray が表示するのは対応範囲の活動だけで、サイトの全動作を監査する機能ではありません。
