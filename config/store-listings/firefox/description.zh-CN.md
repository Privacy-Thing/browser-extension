**看得更多，暴露更少。**

网站能从浏览器中获取的信息，远不止你在表单里输入的内容。它们可能读取地理位置、语言、时区、屏幕尺寸、硬件特征以及其他环境信息。即使是 WebGL 暴露的图形硬件信息，也可能成为可识别浏览器指纹的一部分。

**Privacy Thing** 让你真正掌控这一层面的隐私。它会显示浏览器中当前打开的页面访问了哪些信息和功能，并让你决定其中哪些信息可以被该网站看到——每个网站都可单独设置。

在 Firefox 中，规则还可以分配给容器。同一域名可根据打开时所在的容器使用不同配置。

**简要概览**

1. **Privacy Thing 让你控制浏览器提供的信息**，包括向网站和 Web 应用提供哪些内容。
2. **查看哪些数据被使用，以及使用了多少次。**
3. **为每个网站和 Firefox 容器分别创建多套规则。**
4. **根据地理位置、可用语言和区域偏好创建多套位置配置。**Privacy Thing 提供完整的 GPS 定位模拟功能，并采用贴近真实移动的模型。
5. **Privacy Thing 尽可能在不连接外部服务的情况下提供丰富功能。**你的设置始终由你掌控。

**Privacy Thing 能为你做什么**

1. **减少浏览器指纹中的部分特征** — 根据浏览器和配置，Privacy Thing 可以控制或修改与浏览器、屏幕和硬件相关的部分信息，以及 canvas、WebGL、音频、WebRTC、frame 和 worker 中的选定数据。其中也包括可能暴露图形硬件特征的部分信息。Privacy Thing 提供一组具体工具，用于限制和整理扩展实际能够触及的信息。

2. **看清网站在读取什么** — X-Ray 可以显示网站是否访问了地理位置、语言、屏幕数据、canvas、WebGL、音频、WebRTC 或部分 worker 机制。你还可以查看当前生效的配置，以及某个支持的类别是否出现问题。它并不是网站全部行为的完整日志，而是对 Privacy Thing 能够识别和控制的浏览器区域提供清晰、实用的视图。

3. **为每个网站设定自己的规则** — 创建配置并将其分配给域名或域名模式。你可以使用默认规则、为特定网站添加例外，也可以临时关闭 Privacy Thing，而无需删除现有配置。你还可以只在自己选定的网站上使用扩展；Privacy Thing 不会强迫你采用单一的工作方式。

4. **在 Firefox 容器之间分离设置** — 同一网站可根据容器使用不同配置。这是一种区分工作环境、账户和使用场景的便捷方式。

5. **创建一致的区域配置** — 组合坐标、地理位置精度与坐标随机偏移范围、主要语言、语言列表和时区。首次运行向导可帮助你快速选择现成的区域预设，而自定义配置之后仍可自由编辑。Refract 引擎可以协调 Geolocation API、`navigator.language`、`navigator.languages`、`Date`、`Intl` 和 `Accept-Language` 等值，避免网站看到位置来自一个国家、语言来自另一个国家、时区又来自第三个地区的混乱组合。

6. **使用贴近真实情况的数据，避免不必要的联网请求** — 每个 Privacy Thing 版本都包含由公开数据加工而成的小型本地数据目录。借助这些目录，扩展无需发出额外请求，即可自行选择统计上合理的硬件配置，包括合适的屏幕分辨率、CPU 核心数和可用内存值。Privacy Thing 还可以轮换网站可见的浏览器版本。扩展同时内置浏览器支持的语言代码和各地区官方语言目录。这些数据随扩展一同提供，并通过更新定期刷新。正常应用配置时，Privacy Thing 无需访问原始数据源。时区也可以根据坐标在本地计算。

7. **清理指定网站的数据** — Privacy Thing 可以清除当前域名的数据，包括 Cookie、`localStorage`、`sessionStorage`、`IndexedDB`、`Cache Storage` 和 Service Worker。无论是保护隐私，还是从干净状态测试网站，这项功能都很实用。操作完成后，配置会获得一套完全不同的参数，从而应能显著增加网站持续跟踪活动的难度。

**你的数据，由你决定。**

配置、规则和设置保存在本地浏览器中。核心功能不需要账户或 Privacy Thing 服务器。扩展不自行收集遥测数据，也不会出售数据。

预设、本地数据集和手动坐标无需地图服务。地点搜索与地图预览只会在你主动选择后使用 OpenStreetMap Nominatim 和 OpenFreeMap。

**隐私保护分不同层次**

Privacy Thing 工作在浏览器层。它不会改变公共 IP，不会转发或加密流量，也不能替代 VPN、代理或 Smart DNS。

这些工具可以相互补充：网络服务影响连接或名称解析，而 Privacy Thing 管理浏览器 API 暴露的选定信息。

Privacy Thing 不保证匿名性，也不保证这些修改无法被检测。网站仍可能使用 IP、账户、会话以及扩展无法控制的其他信号。X-Ray 只显示支持范围内的活动，并不是对网站全部行为的完整审计。
