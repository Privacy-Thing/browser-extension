**看得更多，暴露更少。**

網站能從瀏覽器取得的資訊，遠不止你在表單裡輸入的內容。它們可能讀取地理位置、語言、時區、螢幕尺寸、硬體特徵，以及其他環境資訊。即使是 WebGL 透露的圖形硬體資訊，也可能成為可辨識瀏覽器指紋的一部分。

**Privacy Thing** 讓你實際掌控這一層的隱私。它會顯示瀏覽器中目前開啟的頁面存取了哪些資訊和功能，並讓你決定其中哪些資訊可以被該網站看到——每個網站都能個別設定。

在 Firefox 中，規則也可以指派給容器。因此，同一個網域可依你開啟它時所在的環境使用不同的設定檔。

**簡要概覽**

1. **Privacy Thing 讓你控制資訊**，也就是瀏覽器提供給網站和網頁應用程式的內容。
2. **查看網站使用了哪些資訊，以及使用了幾次。**
3. **建立多組規則**，可針對每個網站和 Firefox 容器分別設定。
4. **建立多組位置設定**，依地理位置、可用語言和地區偏好而定。Privacy Thing 提供完整的 GPS 定位模擬功能，並採用貼近真實移動的模型。
5. **Privacy Thing 盡可能在不連線到外部服務的情況下提供豐富功能。**你的設定一律由你掌控。

**Privacy Thing 能為你做什麼**

1. **減少瀏覽器指紋中的部分特徵** — 依瀏覽器和設定而定，Privacy Thing 可以控制或修改與瀏覽器、螢幕和硬體相關的部分資訊，以及 canvas、WebGL、音訊、WebRTC、frame 和 worker 中的選定資料。其中也包括可能透露圖形硬體特徵的部分資料。Privacy Thing 提供一組具體工具，用來限制和整理此擴充功能實際能夠觸及的資訊。

2. **看清網站在讀取什麼** — X-Ray 可以顯示網站是否存取了地理位置、語言、螢幕資料、canvas、WebGL、音訊、WebRTC 或部分 worker 機制。你也可以查看目前套用的設定檔，以及某個支援的類別是否發生問題。它並不是網站所有行為的完整記錄，而是針對 Privacy Thing 能夠辨識和控制的瀏覽器範圍，提供實用的檢視。

3. **為每個網站訂定自己的規則** — 建立設定檔，並將它指派給網域或網域比對模式。你可以使用預設規則、為特定網站新增例外，也可以暫時關閉 Privacy Thing，而不必刪除現有設定。你也可以只在自己選定的網站上使用此擴充功能；Privacy Thing 不會強迫你採用單一的使用方式。

4. **在 Firefox 容器之間分開設定** — 依容器為同一個網站指派不同的設定檔。這樣可以方便地區分工作情境、帳戶和使用情境。

5. **建立一致的地區設定檔** — 結合座標、地理位置精確度與座標隨機偏移範圍、主要語言、語言清單和時區。首次執行精靈可協助你快速選擇現成的地區預設集，而你自己的設定檔之後仍可自由編輯。Refract 引擎可以協調 Geolocation API、`navigator.language`、`navigator.languages`、`Date`、`Intl` 和 `Accept-Language`，避免網站看到位置來自一個國家、語言來自另一個國家、時區又來自第三個地區的混亂組合。

6. **使用貼近真實情況的資料，避免不必要的網路請求** — 每個 Privacy Thing 版本都包含由公開資料加工而成的精簡本機資料目錄。借助這些目錄，此擴充功能無需發出額外請求，即可自行選擇統計上合理的硬體設定檔，包括合適的螢幕解析度、CPU 核心數和可用記憶體值。Privacy Thing 也可以輪替網站所見的瀏覽器版本。此擴充功能同時內建瀏覽器支援的語言代碼，以及各地區官方語言的目錄。這些資料隨擴充功能一併提供，並透過更新定期重新整理。正常套用設定檔時，Privacy Thing 不需要查詢原始資料來源。時區也可以根據座標在本機判定。

7. **清除指定網站的資料** — Privacy Thing 可以清除目前網域的資料，包括 Cookie、`localStorage`、`sessionStorage`、`IndexedDB`、`Cache Storage` 和 Service Worker。無論是為了保護隱私，還是從乾淨狀態測試網站，這項功能都很實用。操作完成後，設定檔會取得一組完全不同的參數，應能大幅增加網站持續追蹤活動的難度。

**你的資料，由你決定。**

設定檔、規則和設定都儲存在瀏覽器本機。核心功能不需要 Privacy Thing 帳戶或後端伺服器。此擴充功能不會自行收集遙測資料，也不會出售資料。

內建預設集、本機資料目錄和手動輸入的座標，都不需要向地圖服務發出請求。只有在你主動啟用地點搜尋或地圖預覽時，才會使用 OpenStreetMap Nominatim 和 OpenFreeMap。

**隱私保護分成不同層次**

Privacy Thing 在瀏覽器層運作。它不會變更你的公開 IP 位址，不會轉送或加密網路流量，也不能取代 VPN、代理伺服器或 Smart DNS 服務。

這些工具可以互相搭配：網路工具影響連線或名稱解析層，Privacy Thing 則控制透過瀏覽器 API 公開的選定資訊。

Privacy Thing 不保證匿名性，也不保證無法被偵測。網站還可能使用 IP 位址、帳戶資料、工作階段，以及此擴充功能無法控制的其他資訊。X-Ray 只回報支援範圍內的活動，並不是對網站所有行為的完整稽核。
